## 🚀 使い方

1.  上記のリンクをタップ、またはブラウザに貼り付けて開く
2.  初回は「
3.  画面上部のステージ／レベルタブから、挑戦したい章を選ぶ（順番の縛りはありません）
4.  表示された物語を読み、取引の内容を読み取る
5.  「借方（Debit）」「貸方（Credit）」それぞれに、勘定科目名と金額を入力する
6.  判定ボタンを押して、正解・不正解を確認する
7.  全問に正解すると、その章の結末が表示されます

間違えた問題は、結果画面から「間違えた問題だけ復習する」でまとめて解き直せます。

**次回以降について**：同じリンクをブックマークまたはホーム画面に追加しておくと、いつでもすぐに開けて便利です。進捗はご自身のブラウザ内に保存されるので、同じ端末・同じブラウザで開けば続きから再開できます。

## 🎨 カスタマイズ方法（上級者向け）

画面下部の **「📥 追加の商談記録を取り込む」**（異世界転生屋台）または **「📥 クラスター設定をインポート」**（ダークウェブプロトコル）を開くと、JSONを貼り付ける窓が**1つ**あります。 この窓から、**見た目のテーマ設定**と**ステージの問題データ**の両方を差し替えることができます。

テーマには、配色・タイトル・ロゴ・ボタンの文言・舞い上がる絵文字に加えて、**文字のフォント**も指定できます（フォントは任意です）。フォントを指定しなければ、元のフォント（ダークウェブは端末風、異世界転生屋台はファンタジー風）のままです。

好きな世界観にカスタマイズしたい場合は、以下のプロンプトをChatGPT・Gemini・Claudeなど お好きなAIチャットに貼り付けてご利用ください。

**反映手順**

1.  上のプロンプトの【　】部分を埋めて、好きなAIチャットに貼り付ける
2.  返ってきた①（テーマ設定）と②（問題データ）を、窓にそのまま貼り付けて、「取り込む」ボタン（ダークウェブプロトコルは「パッチを適用」）を押す。①と②は、続けて1回で貼っても、1つずつ2回に分けて貼っても大丈夫です
3.  反映されると、配色・タイトル・ボタンの文言（フォントを指定した場合はフォントも）と、5ステージ分の問題が切り替わります。タブの名前も、新しい章のタイトルになります

窓は、貼り付けた内容の種類（テーマ／5ステージ分の問題／今開いている章だけの問題）を自動で見分けます。今開いている章だけを差し替えたいときは、その章のタブを開いてから、`[ { "story": ... }, ... ]` の形の配列を貼り付けてください。

フォントは、Google Fontsに実在する名前だけが使えます。名前が違っていたり、読み込めなかったりしたときは、元のフォントで表示されます（表示は崩れません）。フォントの読み込みにはインターネット接続が必要です。

テーマだけを元に戻したいときは、窓の下の「テーマだけ初期値に戻す」を押します。問題も含めてすべて元に戻すときは、画面の一番下にある初期化のリンクを使います。

> ⚠️ AIの回答が稀に不完全（金額の記載漏れなど）になることがあります。 うまく反映されない場合は、「①と②を、指定した形式・ルールを厳守してもう一度出力してください」と 伝えて再生成してみてください。
>
> ⚠️ 取り込みでエラーが出たときは、画面に「○ステージ目の○問目」のように場所が表示されます。その内容をAIに伝えて、「その部分を直して出力し直して」と頼むと、早く直せます。
>
> ⚠️ カスタマイズ内容は、ご自身の端末・ブラウザにのみ保存されます。別の端末で同じリンクを開いた場合は、 初期状態（本来の世界観）から始まります。
